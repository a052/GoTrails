# { title }

Du kannst **GoTrails** verwenden, um Karten zu erstellen, die deine GPX-Dateien zeigen und sie in deine Webseite einbinden.

Alles, was Sie brauchen, sind GPX-Dateien, die auf Ihrem Server oder auf Google Drive gehostet werden oder über eine öffentliche URL zugänglich sind.

Sie können dann mit dem Konfigurator unten spielen, um Ihre Karte anzupassen und den entsprechenden HTML-Code zu generieren.

<DocsNote type="warning">

Sie müssen <a href="https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS" target="_blank">Cross-Origin Resource Sharing (CORS)</a> Header auf Ihrem Server einrichten, um <b>GoTrails</b> um die GPX-Dateien zu laden.

</DocsNote>
