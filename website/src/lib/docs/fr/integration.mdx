# { title }

Vous pouvez utiliser **GoTrails** pour créer des cartes affichant vos fichiers GPX et les intégrer à votre site web.

Tout ce dont vous avez besoin, ce sont des fichiers GPX hébergés sur votre serveur ou sur Google Drive, ou accessibles via une URL publique.

Vous pouvez ensuite jouer avec le configurateur ci-dessous pour personnaliser votre carte et générer le code HTML correspondant.

<DocsNote type="warning">

Vous devrez configurer les headers <a href="https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS" target="_blank">Cross-Origin Resource Sharing (CORS)</a> sur votre serveur de manière à autoriser <b>GoTrails</b> à charger vos fichiers GPX.

</DocsNote>
